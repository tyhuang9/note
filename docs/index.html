Get started

Download for your desktop

Every release includes checksums. Download only from the official GitHub release.

Windows

Install Note for the current user with the NSIS installer.

Download Note-Setup.exe

macOS

Open the disk image and move Note to Applications.

Download Note.dmg

Debian / Ubuntu

Install the Debian package with your package installer or apt.

Download Note.deb

Some Linux releases also include an AppImage. It is optional because AppImage packaging is not reliable on every hosted CI run. Check the latest release files for Note.AppImage.

First use

Start with a page, then make it yours.

  1. Create or select a page from the sidebar.
  2. Click the canvas to add text, then draw, select, pan, and zoom with the tools.
  3. Find what matters with search and choose a theme that fits your space.

Note stores workspace data locally in its application-data directory. There is no cloud sync or automatic backup, so keep your own backup before clearing app data or moving devices.

Note is local-first. Read the full installation guide.
