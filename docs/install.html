Installation guide

Install Note on your desktop.

Think. Capture. Connect.

A freeform canvas for notes, ideas, and everything in between. Choose the package for your platform from the official GitHub release.

Windows

  1. Download Note-Setup.exe.
  2. Run the installer. It installs Note for the current user and does not require administrator access.
  3. Open Note from the Start menu.

macOS

  1. Download Note.dmg.
  2. Open the disk image and drag Note to Applications.
  3. Launch Note from Applications.

Debian and Ubuntu

Download Note.deb, open it in your package installer, or run: 

sudo apt install ./Note.deb

When a release includes Note.AppImage, download it from the release page, make it executable with chmod +x Note.AppImage, and run it.

Unsigned builds

Current Windows, macOS, and Linux packages are unsigned; macOS builds are also not notarized. SmartScreen or Gatekeeper can warn before the first launch. Verify that the file came from the official GitHub release and compare it with SHA256SUMS when needed.

Data and updates

Note keeps pages, canvas elements, assets, and preferences locally in its application-data directory. It has no cloud sync, automatic backup, or built-in automatic updater today.

To update, install a newer package from GitHub Releases over the existing app. Back up important local data before an update, device move, or application-data cleanup.

Build from source

With Node.js, Rust stable, and the Tauri prerequisites installed:

npm --prefix frontend ci
npm run dev
